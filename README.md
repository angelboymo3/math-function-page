# 함수, 연결하고 되돌리다

고등학교 1학년 **2022 개정 공통수학2**의 함수와 그래프를 학습하는 웹페이지입니다. 함수, 합성함수, 역함수, 유리함수의 개념과 연습문제 4개, 펼쳐 볼 수 있는 정답·풀이를 제공합니다. 화면 크기에 맞춘 레이아웃과 인쇄 / PDF 저장 기능을 포함합니다.

HTML, CSS, JavaScript로 구성되어 있으며, 별도 설치 없이 `index.html`을 브라우저에서 열어 사용할 수 있습니다.

## 함수 그래프 탐색

핵심 개념 아래에서 함수·합성함수·역함수 모드를 선택할 수 있습니다. 예시를 고르거나 `2x+1`, `−x+2`, `0.5*x−1`, `3`처럼 일차식·상수식을 입력한 뒤 **그래프 그리기**를 누르세요. 역함수 모드는 원함수와 역함수, `y=x`를 함께 표시합니다. 상수함수는 역함수가 없음을 안내합니다. 새 기능은 [10공수2-03-01]~[10공수2-03-03] 범위이며 기존 유리함수 자료는 유지합니다.

외부 라이브러리 없이 SVG와 JavaScript로 실행됩니다. 분수·괄호·거듭제곱 입력은 지원하지 않습니다.

### 검증

Node.js가 설치되어 있으면 `node tests/graph.test.cjs`로 입력 해석, 합성·역함수 계산, 좌표 변환, 모드 전환과 오류 복구를 검사할 수 있습니다. DOM 검사는 간단한 테스트 대역을 사용하므로 실제 브라우저의 배치 검사를 대신하지 않습니다.

추가 수동 확인: 화면 너비 320·375·768·1024px에서 가로 넘침과 글자 겹침, 키보드 조작, 인쇄 미리보기에서 그래프·풀이 표시 및 인쇄 후 정답 펼침 상태 복원을 확인합니다.

실제 Chrome 검사도 수행했습니다. `tests/browser-check.cjs`는 현재 `index.html`로 브라우저 검증 페이지를 생성합니다. 모드 전환, 오류 복구, 네 화면 너비에서의 가로 넘침과 축 비율, 인쇄 스타일 및 정답 상태 복원 등 38개 검사를 통과했습니다. 결과는 `tests/browser-report.json`, 375px 화면 캡처는 `tests/graph-mobile.png`에 저장했습니다. 인쇄 검사는 인쇄 이벤트와 CSS 규칙 검사이며 실제 프린터 출력을 의미하지 않습니다.
