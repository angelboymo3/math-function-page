함수, 연결하고 되돌리다.

함수의 대응을 이해하고, 두 함수를 연결하고, 입력과 출력을 되돌려 봅시다.

시작 전 떠올리기집합과 대응 · 일차함수의 함숫값 · 좌표와 그래프
예를 들어 y = 2x + 1에서 x = 1이면 y = 3, 그래프 위의 점은 (1, 3)입니다.선수학습은 이 자료의 학습을 돕기 위한 권장 복습 내용입니다.

01 / 세 가지 핵심 개념

[10공수2-03-01]

함수 · 하나씩 대응

정의역의 각 원소에 공역의 원소가 오직 하나씩 대응하면 함수입니다.

정의역은 입력 전체, 공역은 출력이 속하도록 정한 집합, 치역은 실제 출력의 집합입니다.

그래프는 (x, f(x))인 점들의 모임입니다. 아래 그래프에서 y = 2x + 1 위의 점 (1, 3)을 찾아보세요.

[10공수2-03-02]

합성함수 · 연결하기

한 함수의 출력을 다음 함수의 입력으로 사용합니다. 오른쪽 함수부터 적용합니다.

(g ∘ f)(x) = g(f(x))
x → f → g → g(f(x))

f(x) = x + 1, g(x) = 2x라면

x → x + 1 → 2x + 2

따라서 (g ∘ f)(x) = 2x + 2입니다.

f의 출력이 g의 정의역에 속해야 연결할 수 있습니다. 일반적으로 g ∘ f와 f ∘ g는 서로 다릅니다.

[10공수2-03-03]

역함수 · 되돌리기

입력과 출력을 바꾸는 함수입니다. 원래 함수가 일대일대응이면 역함수가 존재합니다.

서로 다른 입력의 출력이 다르고, 치역이 공역 전체와 같아야 합니다.

f(a) = b ⇔ f⁻¹(b) = a

y = 2x − 3에서 x와 y를 바꾼 뒤 y에 대해 풀면

f⁻¹(x) = (x + 3) / 2

두 그래프는 직선 y = x에 대칭입니다. f⁻¹(x)는 1/f(x)와 다릅니다.

02 / 내 힘으로 확인하기

먼저 풀고, 정답·풀이를 펼쳐 확인하세요.

기초01

[10공수2-03-01] 함수와 그래프f(x) = 2x + 1에서 f(2)와 그래프 위 x = 2인 점의 좌표를 구하시오.

정답·풀이 보기

정답: f(2) = 5, 좌표는 (2, 5)

x에 2를 대입하면 2 × 2 + 1 = 5입니다. 그래프 위의 점은 (입력, 출력)으로 나타냅니다.

기본02

[10공수2-03-02] 합성함수f(x) = x + 1, g(x) = 2x일 때 (g ∘ f)(x)와 (f ∘ g)(x)를 구하시오. (정의역과 공역은 실수 전체)

정답·풀이 보기

정답: (g ∘ f)(x) = 2x + 2, (f ∘ g)(x) = 2x + 1

g(f(x)) = 2(x + 1), f(g(x)) = 2x + 1입니다. 연결 순서를 바꾸면 결과도 달라집니다.

도전03

[10공수2-03-03] 역함수실수 전체에서 실수 전체로의 함수 f(x) = 2x − 3의 역함수를 구하고, 두 그래프의 교점을 구하시오.

정답·풀이 보기

정답: f⁻¹(x) = (x + 3) / 2, 교점은 (3, 3)

일대일대응이므로 역함수가 존재합니다. x = 2y − 3을 y에 대해 풀면 y = (x + 3) / 2입니다. 교점에서는 2x − 3 = (x + 3) / 2이므로 4x − 6 = x + 3, x = 3, y = 3입니다.

다음 시간 → 합성함수와 역함수의 관계를 더 연습합니다. f⁻¹(f(x))가 왜 x인지 생각해 보세요.
