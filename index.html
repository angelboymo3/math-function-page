함수, 연결하고 되돌리다.

함수의 대응을 이해하고, 두 함수를 연결하고, 입력과 출력을 되돌려 봅시다.

시작 전 떠올리기집합과 대응 · 일차함수의 함숫값 · 좌표와 그래프
예를 들어 y = 2x + 1에서 x = 1이면 y = 3, 그래프 위의 점은 (1, 3)입니다.선수학습은 이 자료의 학습을 돕기 위한 권장 복습 내용입니다.

01 / 세 가지 핵심 개념

[10공수2-03-01]

함수 · 하나씩 대응

정의역의 각 원소에 공역의 원소가 오직 하나씩 대응하면 함수입니다.

정의역은 입력 전체, 공역은 출력이 속하도록 정한 집합, 치역은 실제 출력의 집합입니다.

그래프는 (x, f(x))인 점들의 모임입니다. 아래 그래프에서 y = 2x + 1 위의 점 (1, 3)을 찾아보세요.

[10공수2-03-02]

합성함수 · 연결하기

한 함수의 출력을 다음 함수의 입력으로 사용합니다. 오른쪽 함수부터 적용합니다.

(g ∘ f)(x) = g(f(x))
x → f → g → g(f(x))

f(x) = x + 1, g(x) = 2x라면

x → x + 1 → 2x + 2

따라서 (g ∘ f)(x) = 2x + 2입니다.

f의 출력이 g의 정의역에 속해야 연결할 수 있습니다. 일반적으로 g ∘ f와 f ∘ g는 서로 다릅니다.

[10공수2-03-03]

역함수 · 되돌리기

입력과 출력을 바꾸는 함수입니다. 원래 함수가 일대일대응이면 역함수가 존재합니다.

서로 다른 입력의 출력이 다르고, 치역이 공역 전체와 같아야 합니다.

f(a) = b ⇔ f⁻¹(b) = a

y = 2x − 3에서 x와 y를 바꾼 뒤 y에 대해 풀면

f⁻¹(x) = (x + 3) / 2

두 그래프는 직선 y = x에 대칭입니다. f⁻¹(x)는 1/f(x)와 다릅니다.

함수 그래프 탐색

[10공수2-03-01] 함수 · [10공수2-03-02] 합성함수 · [10공수2-03-03] 역함수

일차식·상수식만 입력하세요: y = 2x + 1, −x + 2, 0.5*x − 1, 3. 분수·괄호·거듭제곱은 지원하지 않습니다. 정의역과 공역은 실수 전체입니다.

표시 범위는 두 축 모두 −10~10입니다. 화면 밖에서도 함수는 이어집니다. 소수는 최대 네 자리로 표시하며, 반올림한 값에는 ≈를 붙입니다.

02 / 내 힘으로 확인하기

먼저 풀고, 정답·풀이를 펼쳐 확인하세요.

기초01

[10공수2-03-01] 함수와 그래프f(x) = 2x + 1에서 f(2)와 그래프 위 x = 2인 점의 좌표를 구하시오.

정답·풀이 보기

정답: f(2) = 5, 좌표는 (2, 5)

x에 2를 대입하면 2 × 2 + 1 = 5입니다. 그래프 위의 점은 (입력, 출력)으로 나타냅니다.

기본02

[10공수2-03-02] 합성함수f(x) = x + 1, g(x) = 2x일 때 (g ∘ f)(x)와 (f ∘ g)(x)를 구하시오. (정의역과 공역은 실수 전체)

정답·풀이 보기

정답: (g ∘ f)(x) = 2x + 2, (f ∘ g)(x) = 2x + 1

g(f(x)) = 2(x + 1), f(g(x)) = 2x + 1입니다. 연결 순서를 바꾸면 결과도 달라집니다.

도전03

[10공수2-03-03] 역함수실수 전체에서 실수 전체로의 함수 f(x) = 2x − 3의 역함수를 구하고, 두 그래프의 교점을 구하시오.

정답·풀이 보기

정답: f⁻¹(x) = (x + 3) / 2, 교점은 (3, 3)

일대일대응이므로 역함수가 존재합니다. x = 2y − 3을 y에 대해 풀면 y = (x + 3) / 2입니다. 교점에서는 2x − 3 = (x + 3) / 2이므로 4x − 6 = x + 3, x = 3, y = 3입니다.

다음 시간 → 합성함수와 역함수의 관계를 더 연습합니다. f⁻¹(f(x))가 왜 x인지 생각해 보세요.

03 / 유리함수 · 그래프와 성질

[10공수2-03-04] 성취기준유리함수 y = (ax + b)/(cx + d)의 그래프를 그릴 수 있고, 그 그래프의 성질을 탐구할 수 있다.근거: 교육과정 MCP 공식 원문(officialText) · 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정, PDF 73쪽, 공통수학2 > 함수와 그래프.

분모의 제한과 평행이동으로 이해하기

유리함수는 다항식의 비로 나타낼 수 있는 함수입니다. 정의역을 따로 정하지 않으면 분모가 0이 되지 않는 모든 실수를 정의역으로 합니다.

y = k / (x − p) + q   (k ≠ 0)

이 그래프는 y = k / x의 그래프를 x축 방향으로 p만큼, y축 방향으로 q만큼 평행이동한 것입니다. 정의역은 {x ∈ ℝ | x ≠ p}, 치역은 {y ∈ ℝ | y ≠ q}이고, 두 점근선은 x = p, y = q입니다. 그래프는 점 (p, q)에 대하여 대칭입니다.

점근선은 그래프가 한없이 가까워지는 직선입니다. 이 형태에서는 x가 p에 가까워질 때 함숫값의 절댓값이 한없이 커지고, x의 절댓값이 한없이 커질 때 y가 q에 가까워집니다. 그래프는 두 점근선과 만나지 않습니다.

k > 0이면 x > p에서 y > q, x < p에서 y < q입니다. k < 0이면 그 위치가 반대입니다. 점근선을 먼저 그리고, 몇 개의 점을 표시한 뒤 두 곡선을 부드럽게 이어 그립니다.

y = (ax + b)/(cx + d)에서 c ≠ 0, ad − bc ≠ 0이면 p = −d/c, q = a/c, k = (bc − ad)/c²로 위 형태를 얻습니다. ad − bc = 0이면 정의역에서 일정한 값을 갖는 함수이므로 위 쌍곡선의 성질을 그대로 적용하지 않습니다.

기본04

[10공수2-03-04] 유리함수유리함수 y = (2x + 1) / (x − 1)의 정의역, 치역, 두 점근선을 구하고, 좌표축과 만나는 점을 표시하여 그래프의 개형을 그리시오. (정의역은 식이 정의되는 모든 실수)

정답·풀이 보기

정답: 정의역 {x ∈ ℝ | x ≠ 1}, 치역 {y ∈ ℝ | y ≠ 2}, 점근선 x = 1과 y = 2. x축과의 교점은 (−1/2, 0), y축과의 교점은 (0, −1)입니다.

2x + 1 = 2(x − 1) + 3이므로 y = 2 + 3 / (x − 1)입니다. y = 3 / x의 그래프를 x축 방향으로 1만큼, y축 방향으로 2만큼 평행이동합니다. 분모 때문에 x ≠ 1이고, 3 / (x − 1)은 0이 될 수 없으므로 y ≠ 2입니다. 반대로 y ≠ 2인 모든 실수에 대해 x = 1 + 3 / (y − 2)를 택할 수 있으므로 치역은 2를 제외한 모든 실수입니다.

y = 0이면 2x + 1 = 0에서 x = −1/2이며 분모는 0이 아닙니다. x = 0이면 y = −1입니다. 점근선 x = 1, y = 2를 점선으로 그리고, 왼쪽 아래 가지에는 (−1/2, 0), (0, −1)을, 오른쪽 위 가지에는 (2, 5), (4, 3)을 표시합니다. 점 (1, 2)를 중심으로 대칭인 두 가지를 점근선에 가까워지도록 그립니다.

검산: x = 2일 때 원래 식은 (4 + 1)/(2 − 1) = 5이고, 변형한 식도 2 + 3/(2 − 1) = 5입니다. x = 4일 때도 두 식의 값은 모두 3입니다.
