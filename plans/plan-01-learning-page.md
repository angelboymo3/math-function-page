# 학습자료 및 그래프 기능 계획 01 · 공통수학2

## 목적과 범위

고등학교 1학년 학생이 함수, 합성함수, 역함수, 유리함수의 개념을 이해하고 문제로 확인할 수 있는 학습 페이지를 만든다. 기존 `index.html`의 내용과 기능을 유지하면서 유리함수 설명, 문제 1개, 정답·풀이를 별도 절로 추가한다. 전체 연습문제는 4개로 구성한다.

핵심 개념과 연습문제 사이에 학생이 함수식을 선택하거나 직접 입력하는 그래프 탐색 기능을 추가한다. 외부 라이브러리 없이 HTML·CSS·순수 JavaScript와 SVG를 사용한다. 직접 입력은 일차식·상수식으로 제한하며, 새 그래프 기능의 교육과정 범위는 [10공수2-03-01]~[10공수2-03-03]이다. 기존 [10공수2-03-04] 유리함수 학습자료는 유지한다.

## 페이지 구성

1. **도입**: 제목, 학습 안내, 집합과 대응·일차함수·좌표와 그래프에 관한 선수학습 안내를 둔다.
2. **세 가지 핵심 개념**: 함수의 정의역·공역·치역, 합성함수의 적용 순서, 역함수의 의미와 그래프 대칭을 설명한다. 기존 예시와 그림을 유지한다.
3. **함수 그래프 탐색**: 단원 선택, 예시 선택, 함수식 입력, 그래프 그리기 버튼, SVG 그래프, 계산식과 범례를 배치한다. 함수·합성함수·역함수의 세 모드를 제공한다.
4. **기존 연습문제**: 함숫값과 좌표, 합성함수, 역함수와 교점을 묻는 3문제 및 펼쳐 보는 정답·풀이를 유지한다.
5. **유리함수 추가 절**: 공식 성취기준과 출처를 제시하고, `y = k/(x − p) + q (k ≠ 0)`의 평행이동, 정의역·치역, 점근선과 대칭을 설명한다. 일반식에서 이 형태로 바꾸는 조건도 명시한다.
6. **유리함수 문제 1개**: `y = (2x + 1)/(x − 1)`의 정의역·치역·점근선·좌표축과의 교점을 구하고 그래프 개형을 그리게 한다. 정답과 식 변형, 점 표시를 통한 그래프 작성 안내, 검산을 제공한다.
7. **출처와 편의 기능**: 교육과정 근거를 표시하고, 모바일 대응 레이아웃, 정답 펼치기, 인쇄 / PDF 저장 기능을 유지한다.

프로젝트 소개, 성취기준, MCP 출처, 배포 주소, 제작 과정 3줄 요약은 `README.md`에 정리한다. 배포 주소는 https://angelboymo3.github.io/math-function-page/ 이다.

## 그래프 기능 구성

| 모드와 성취기준 | 초기 함수식 | 표시 내용 |
| --- | --- | --- |
| 함수 · [10공수2-03-01] | `f(x) = 2x + 1` | 함수 그래프와 x가 −2, −1, 0, 1, 2일 때의 함숫값 표 |
| 합성함수 · [10공수2-03-02] | `f(x) = x + 1`, `g(x) = 2x` | `g∘f`, `f∘g`의 계산식과 두 그래프 |
| 역함수 · [10공수2-03-03] | `f(x) = 2x − 3` | 원함수, 자동 계산한 역함수, 대칭 기준선 `y = x` |

- **선택과 입력**: 공통 예시 `2x+1`, `−x+2`, `x`, `3`을 제공하고, 합성함수 모드에는 `x+1`, 역함수 모드에는 `2x−3`을 추가한다. 예시 선택 시 즉시 갱신하고 직접 입력은 버튼 또는 Enter로 적용한다. 모드를 변경하면 해당 초기값으로 전환한다.
- **입력 문법**: `ax+b`, `ax`, 상수를 지원한다. 정수·소수, 생략된 계수 `x`·`−x`, `2*x`, 선택적인 `y=`·`f(x)=` 접두사를 허용한다. g 입력란은 `g(x)=`도 허용한다. 공백과 유니코드 빼기를 정규화하며, 분수·괄호·거듭제곱·함수 호출은 지원하지 않는다.
- **안전한 계산**: 입력은 80자 이내로 제한하고 전체 문자열을 검사하여 계수로 변환한다. `eval`·`new Function`은 사용하지 않으며, 입력 내용은 `textContent`로 표시한다. 계수와 계산 결과의 유한성을 확인한다.
- **수학적 처리**: `f=ax+b`, `g=cx+d`이면 `g∘f=acx+cb+d`, `f∘g=acx+ad+b`로 계산한다. 정의역과 공역은 실수 전체이며 `a ≠ 0`인 함수의 역함수는 `(x−b)/a`이다. 상수함수는 수평선으로 그리되 역함수가 없음을 안내한다.
- **좌표와 범례**: 정사각형 SVG에 두 축 모두 −10~10을 표시하고 축의 단위 길이를 같게 유지한다. 직선을 좌표 영역에 맞춰 잘라 그리며 화면 밖에서도 함수가 이어짐을 안내한다. 이름·색상·선 모양으로 그래프를 구분하고, 겹치는 그래프와 표시 범위 밖의 그래프를 설명한다.
- **수치 표시**: 내부 계산값은 유지하고 화면의 소수는 최대 네 자리로 표시한다. 반올림 값에는 `≈`를 붙인다.
- **오류 처리**: 잘못된 입력에는 구체적인 오류와 입력 예시를 제공하고 이전 그래프·계산 결과를 지운다. 정상 입력으로 수정하면 다시 그릴 수 있어야 한다.
- **모바일·접근성·인쇄**: SVG 너비를 화면에 맞추고 좁은 화면에서는 조작부를 세로로 배치한다. 입력 글자 크기는 최소 16px, 버튼 높이는 최소 44px로 한다. 입력 레이블, SVG 설명, 오류 알림과 키보드 조작을 지원한다. 인쇄 시 조작부를 숨기고 현재 그래프·식·범례를 유지한다.

## 확인 기준과 오류 검증 방법

아래 항목은 학습자료의 확인 기준이며, 모든 항목의 검증 완료를 뜻하지는 않는다.

- **교육과정 정합성**: 성취기준 코드와 문구가 MCP 공식 원문에 부합하고, 문서명과 PDF 쪽수가 명시되어 있다. 직접 제작한 설명·문제와 공식 원문을 구분한다.
- **기존 내용 보존**: 기존 개념, 그림, 문제 3개, 정답, 출처와 기능을 삭제하거나 변경하지 않고 유리함수 절을 추가한다.
- **수식의 조건**: 분모가 0인 값을 정의역에서 제외한다. 쌍곡선 성질은 `k ≠ 0`일 때 설명하며, 일반식에서는 `c ≠ 0`, `ad − bc ≠ 0` 조건을 명시한다.
- **유리함수 정답**: `(2x + 1)/(x − 1) = 2 + 3/(x − 1)`을 확인한다. 정의역은 1을 제외한 모든 실수, 치역은 2를 제외한 모든 실수, 점근선은 `x = 1`, `y = 2`이다.
- **교점과 그래프**: x축과의 교점 `(-1/2, 0)`, y축과의 교점 `(0, -1)`을 대입하여 검산한다. `(2, 5)`, `(4, 3)`이 그래프 위에 있고, 두 가지가 `(1, 2)`에 대하여 대칭이며 점근선에 가까워지는지 확인한다.
- **문제 수와 풀이**: 전체 문제는 4개이고, 새 유리함수 문제는 정확히 1개다. 정답뿐 아니라 식 변형과 그래프 작성 과정도 제공한다.
- **화면과 상호작용**: 한글과 수식이 깨지지 않고 좁은 화면에서도 읽을 수 있다. 정답 펼치기와 인쇄 / PDF 저장이 동작하며, 인쇄 시 풀이가 표시된다.
- **문서 일치**: README의 성취기준, 문제 수, 출처, 배포 주소가 학습 페이지와 일치한다.

### 그래프 기능 확인 기준

- **입력 해석**: `y=2x+1`, `−x+2`, `0.5*x−1`, `3`, `0x+3`을 정확히 해석한다. 빈 입력, `2x+`, `x²`, `1/x`, `alert(1)`, 무한대와 80자 초과 입력은 오류로 처리한다.
- **함수·합성함수 검산**: `2x+1`이 `(0,1)`, `(2,5)`를 지나는지 확인한다. `f=x+1`, `g=2x`의 합성 결과가 각각 `2x+2`, `2x+1`인지 확인한다.
- **역함수·대칭 검산**: `2x−3`의 역함수가 `(x+3)/2`인지 확인한다. `(0,−3)`과 `(−3,0)`의 반사 관계를 확인하고 양수·음수·소수 기울기에서 여러 x에 대해 `f⁻¹(f(x))≈x`를 검사한다.
- **예외와 복구**: 상수함수의 역함수 부재, `f=x`에서 겹치는 세 직선, 음수 기울기, 표시 범위 밖의 그래프를 확인한다. 오류 입력 후 이전 결과가 사라지고 정상 입력 후 복구되어야 한다.
- **실제 화면**: 320·375·768·1024px에서 가로 넘침과 글자 겹침이 없어야 한다. SVG가 정사각형이며 `y=x`가 45도로 표시되고 두 축의 단위 길이가 같아야 한다.
- **회귀와 인쇄**: 기존 문제 4개와 풀이를 유지한다. 인쇄 전 모든 정답을 펼치고 인쇄 후 기존 상태를 복원해야 한다. 인쇄 스타일에서 조작부는 숨기고 그래프는 남겨야 한다.
- **독립 실행**: 외부 라이브러리나 서버 없이 로컬 `index.html`에서 동작하고, 실행 중 JavaScript 오류가 없어야 한다.

### 검증 도구와 기록

- `node tests/graph.test.cjs`: 입력 해석, 합성·역함수 계산, 좌표 변환과 자르기, 간단한 DOM 대역을 이용한 모드 전환·오류 복구를 검사한다.
- `node tests/browser-check.cjs`: 현재 `index.html`을 바탕으로 실제 브라우저에서 열 검증 페이지를 생성한다. 생성만으로 검사가 완료되는 것은 아니며 Chrome에서 실행한 결과를 확인한다.
- 저장된 `tests/browser-report.json`에는 Chrome 검사 38개 통과 결과가 있다. `tests/graph-mobile.png`에는 375px 화면 캡처가 있다.
- 인쇄 관련 자동 검사는 인쇄 이벤트와 CSS 규칙 검증이며, 실제 프린터 출력 검증과 구분한다. 계획의 모든 확인 기준을 이 결과만으로 검증 완료했다고 간주하지 않는다.
